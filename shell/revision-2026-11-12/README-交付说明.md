## 卡住原因

1. 原内腔40×12 mm，PCB STEP约39.975×11.975 mm，单侧仅约0.013 mm理论间隙，打印误差、板边毛刺均足以卡住。与用户反馈的两个短边卡住相符。
2. Type-C模型伸出PCB板边1.367 mm，无法忽略它而只按板框设计装入路径。原封闭孔上桥阻碍从顶部下放。
3. 以原SW副本重新导出的对照实体检查，PCB底面放在原横筋Y=-6.6 mm处时，原壳与组件重叠约3.445 mm³。Type-C最高处超过原孔顶约0.451 mm，因此不仅是打印误差问题。
4. 原装配体两个虚拟零件没有实体，未包含可以用于检查的PCB。

## 修改内容和尺寸

- 底壳外形保留44×16×13 mm，底板2 mm。
- 主腔扩至41.2×13.2 mm，PCB每侧约0.613 mm模型间隙；顶沿原42×14 mm开口保留。
- Type-C侧槽宽11 mm，底部位置保持，向上贯通顶沿；PCB可从上方落入。
- 三道支撑筋中央10.6 mm宽范围降低1 mm；两边保留约0.7 mm宽的支撑，中央让出焊点空间。实际焊点若超过1 mm，应先修整或复核。
- 亚克力盖44×16×2 mm，覆盖顶沿。装配示意胶层0.15 mm，总高度约15.15 mm。顶沿主要粘接面宽1 mm，USB侧局部中断。
- DXF仅一条闭合外轮廓，无孔。尺寸指成品尺寸，切缝补偿交加工方；2 mm厚度写在加工要求中，不能从2D文件推断。

## 验证与装配

修改壳为有效单实体；精确PCB静态干涉0 mm³。将151个PCB实体的各自包围盒沿装入方向扫掠20 mm，逐个检查重叠体积，合计0 mm³（保守包络检查，允许支撑面接触）。亚克力盖与PCB无实体重叠，最高USB模型距盖底约1.699 mm。全部原文件与备份SHA256一致。

打印文件已旋转为Z=0平底、Z=13顶沿；切片软件导入时按毫米，勿自动缩放。主腔为直壁敞口；先打印一件进行板边、焊点和USB线插头试装。

装配顺序：清理打印毛刺 → 焊好PCB从上方落入 → 检查底面焊点和支承位置 → 试插实际USB线并通电测试 → 固定PCB → 顶沿少量施胶并贴透明板。底壳没有卡扣或螺钉压板，透明盖也不压PCB，需在支撑接触位置用少量与板材、外壳兼容的绝缘胶固定PCB，避免插拔时移动。胶种未指定，先用打印废料及亚克力边角料试粘，确认不会使透明盖发白或开裂；勿让胶进入USB和LED。

验证不包含实物手焊焊料形状、板框实测、打印收缩、USB线头包胶外形、胶接强度或LED光学效果。原结构下部横筋不是LED遮光仓，透明顶盖可能存在串光。本次没有修改PCB、采购或下单。

大型PCB检查装配STEP是生成文件，不纳入Git。克隆仓库后执行下述验证脚本即可重新生成。

## 复现

先运行 py -m pip install -r requirements-cad.txt 安装验证时使用的几何依赖。使用 Python 及 cadquery-ocp：`py verify_fit.py` 重做几何验证；`py make_deliverables.py` 生成打印朝向STL、DXF和几何预览（另需vtk）。SLDPRT中的原始特征历史保留，新增特征名称以RevB开头。
