# Agent Light 0.2.1 · Windows 桌面预览版

本次以 **Pre-release** 发布，供 Windows 11 x64 用户试用。自动化和分发验证已通过，仍有实机/手工验收待完成，暂不标记为稳定最新版。

## 下载与安装

- **常规安装**：下载 `AgentLight-0.2.1-windows-x64-setup.exe`，按当前用户安装。
- **便携运行**：下载 `AgentLight-0.2.1-windows-x64.zip`，完整解压后运行 `AgentLight/AgentLight.exe`。
- 桌面包已包含 Python、Qt、console CLI 和完整 DSH 插件，不需要另外安装 Python/PySide6。DSH 和对应 Node 仍由用户自行安装。
- `agent_light-0.2.1-py3-none-any.whl`、`agent-light-dsh-0.1.3-desktop.tgz` 为可选分发，普通桌面用户不必另行安装。

安装前请正常退出旧 Agent Light 和加载此插件的 DSH 后端。程序升级后按需要在“Agent 接入 → DSH”核对接入，再重启 DSH。

本预览版未做代码签名；可使用 Release 附件 `AgentLight-0.2.1-SHA256SUMS.txt` 核对下载文件。

## 本次内容

- PySide6 桌面窗口、托盘、当前用户登录启动、异步服务启停和单实例激活。
- 串口扫描、自动/手动连接、设备确认状态、逐色 ACK 驱动的三色测试及最新业务灯态恢复。
- 亮度与完成保持设置、来源明细、显式停用/重新启用及历史数据保留。
- DSH 宿主版本/指纹检测、配置草稿、受支持 launcher 的旧接入迁移、差异预览、备份、安装及卸载。
- “Agent 接入”二级导航：DSH、Codex、ZCode、WorkBuddy。DSH 是当前已实现的事件适配；其余明确标为待适配，Codex 仅保留只读环境检测。切换页面不改变实际来源的上报。
- 原有 CLI 命令保留。灯板未就绪/测试已运行时，`test` 返回业务错误，不再接受无设备测试。

## 发布前验证

- PC 回归 **35/35**，包含 Qt 导航、输入保留、异步结果隔离、服务生命周期、配置事务和 fake 串口。
- DSH 插件回归 **7/7**。
- 独立中文空格目录运行冻结 GUI/CLI、schema/元数据、完整插件/Worker、资源缺失拒绝及外部 Node 检测通过。
- 本机实际 DSH 0.2.1-rc.2 / Cordis 4.0.5 的只读版本与指纹检测通过。
- 16 个合成会话、1000 条积压事件并开启 Qt 轮询：HTTP p95 4.226ms，模拟 USB 正常最大请求间隔 1.059s；5.3 秒慢盘注入后的快照失效及重新确认通过。性能证据来自当前本机与 fake 串口。

## 已知范围

- 新桌面版的真实灯板联调、实际 DSH 迁移完整链路、Windows 登录启动、交互安装/升级/卸载及第二台机器验收尚未全部完成。
- 三色测试成功表示设备 ACK，不代表光学检测。
- 此 Release 不包含固件更新，也不提供 Codex、ZCode、WorkBuddy 的真实事件适配。
- 卸载会检查已登记的 DSH 引用，并保留配置、token、数据库、outbox、overlay 和备份；手工创建的未登记接入需自行解除。
