# Agent Light FreeRTOS Firmware Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 为已完成的 STM32F042F6P6 Rev A PCB 实现可构建、可测试的 FreeRTOS USB CDC 固件。

**Architecture:** PC 是业务状态唯一权威。固件使用静态 FreeRTOS 任务和缓冲，USB ISR 仅处理 USB 栈和收发队列；单任务管理协议、显示和链路超时，避免共享状态竞争。

**Tech Stack:** C11、STM32CubeF0 HAL/USB、FreeRTOS、ARM GCC；提供 MDK 工程与 CubeMX 配置说明。

**Spec:** outputs/agent-indicator-execution-plan.md §8、§15；hardware/eda/README.md。

## Global Constraints

- STM32F042F6P6，Flash 32 KB、RAM 6 KB。
- PA9/PA10 重映射 USB PA11/PA12；HSI48 + CRS；PA0/1/2 AF2 TIM2_CH1/2/3，10 kHz。
- 协议 v1、payload ≤32、COBS + CRC16-CCITT-FALSE、20–100% 亮度、默认 35%、5 秒看门狗。
- 中文注释；采用 Google C++ 指南中适用 C 的命名、缩进、头文件防护和函数契约说明，厂商文件不改风格。
- 仅 SWD；不写配置 Flash。实物验收和 Cube/Keil GUI 首次确认仍按原计划交给用户。

## Review Focus

- USB 分包/粘包/队列溢出后的完整帧恢复。
- 同 seq 不同请求、重试和 revision 回绕。
- 超时后重试同 revision 必须重新进入 ACTIVE；心跳不能恢复旧灯态。
- USB reset/suspend/resume 与待发送 ACK 的代次隔离。
- RAM/任务栈/USB 分配、ISR 和调度器启动顺序。
